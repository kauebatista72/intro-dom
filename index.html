Conhecendo o DOM

DOM significa Document Object Model

É uma representação do documento HTML em forma de objeto, organizada em uma estrutura de árvore, conhecida como a DOM tree.

Em outras palavras, o navegador transforma o HTML em uma estrutura que o JavaScript consegue acessar e manipular.

Pra que serve o DOM?

O DOM serve para permitir que o JavaScript acesse e manipule o conteúdo e a estrutura de uma página HTML.

  • Seleção de elementos : Encontrar um botão
  • Alterar conteúdo : Alterar um titulo, parágrafo..
  • Alterar estilos : Mudar cores, aplicar bordas e etc
  • Criar elementos : Criar novos elementos HTML
  • Remover elementos : Eliminar elementos existentes
  • Capturar eventos : detectar cliques, teclas pressionadas, etc.
  • modificar atributos :Alterar um src, um arial-label e etc.
